과목선택 검증 결과를 한눈에 확인하세요.

이 브라우저 저장은 새로고침에서만 유지됩니다. 다른 컴퓨터로 옮기거나 만약을 대비해 백업 파일로 내려받아 두세요.
여러 사람과 데이터 공유 — 구글 시트(Apps Script) 주소를 등록하면, 같은 주소를 입력한 모든 선생님이 같은 편성표·학생 데이터를 저장·조회할 수 있습니다.

1) 구글 드라이브에서 새 구글 시트를 하나 만듭니다 (빈 시트면 충분합니다).

2) 상단 메뉴 확장 프로그램 → Apps Script를 클릭합니다.

3) 기본 코드를 지우고, 아래 코드를 복사해서 붙여넣습니다. (데이터를 구글 드라이브 파일에 저장합니다 — 시트 셀은 5만자 제한이 있어 학생 수가 많으면 저장이 잘릴 수 있어 파일 방식을 사용합니다.)

function getDataFile() {
  var fileName = 'juseong_course_data.json';
  var files = DriveApp.getFilesByName(fileName);
  if (files.hasNext()) {
    return files.next();
  }
  return DriveApp.createFile(fileName, '{}', MimeType.PLAIN_TEXT);
}

function doGet(e) {
  var file = getDataFile();
  var value = file.getBlob().getDataAsString();
  return ContentService.createTextOutput(value || '{}')
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var file = getDataFile();
  file.setContent(e.postData.contents);
  return ContentService.createTextOutput(JSON.stringify({status:'ok'}))
    .setMimeType(ContentService.MimeType.JSON);
}

4) 저장(💾) 후 우측 상단 배포 → 새 배포 클릭 → 유형에서 웹 앱 선택.

5) "액세스 권한"을 모든 사용자로 설정하고 배포 → 권한 승인(본인 계정으로, "고급 → 이동(안전하지 않음)"까지 끝까지 진행).

6) 발급된 웹 앱 URL을 복사해서 아래 입력칸에 붙여넣고 저장하세요. 이 URL을 다른 선생님들에게도 공유하면 모두 같은 데이터를 함께 씁니다.

※ 이미 시트 셀 방식(구버전 코드)으로 설정하셨다면, Apps Script 코드를 위 내용으로 통째로 교체한 뒤 배포 → 배포 관리 → 편집(연필) → 새 버전 → 배포로 갱신하면 URL은 그대로 유지한 채 문제만 해결됩니다.
